A Claude Code skill that generates READMEs from codebase analysis. Detects your project type, picks the right section template, and writes prose that passes AI-detection scrutiny.

> This README was generated by write-readme.

## Usage

```
/readme                  # standard
/readme minimal          # short
/readme detailed         # everything
```

The skill reads your codebase, asks a couple of questions, generates the README, and shows it to you for approval before writing to disk.

## What it does

- Detects your project type and picks the right README structure
- Generates content from your actual codebase, not generic templates
- Writes prose that passes AI-detection scrutiny
- Captures screenshots on request (`/screenshot`)
